## 二、四组件 Prompt 核心结构

### ① Perception（感知层）— 共享组件，不属于 TS 特有

```
┌─────────────────────────────────────────────────────────────────┐
│ System: 你是亲子沟通洞见感知层 agent                              │
│                                                                 │
│ 从以下五个维度分析窗口文本:                                        │
│  1. 情感状态 — 家长/孩子的情绪基调                               │
│  2. 核心需求 — 孩子未被满足的心理需求                            │
│  3. 沟通模式 — 对话的互动模式（追逃/协商/冲突）                   │
│  4. 家长盲区 — 家长可能没有意识到的误解                          │
│  5. 弹窗时机 — 此时是否适合弹出洞见                              │
│                                                                 │
│ Input:  window_text (≤300字对话片段)                             │
│ Output: PerceptionReport { 五维标签 + response_need }            │
└─────────────────────────────────────────────────────────────────┘
```

### ② Master / Teacher（总控）— 共享组件

```
┌─────────────────────────────────────────────────────────────────┐
│ System: 你是亲子沟通总控 agent，基于感知+记忆做决策                │
│                                                                 │
│ 决策维度:                                                        │
│  1. 是否弹窗 (should_popup)                                     │
│  2. 弹窗方向 (direction): diagnostic / empowering               │
│  3. 故事弧线 (story_arc) — 跨窗口叙事连续性                      │
│  4. 主要矛盾 (main_contradiction) — 当前窗口的核心紧张            │
│                                                                 │
│ 关键区分标准:                                                    │
│  - diagnostic: 家长存在情绪盲区或认知偏差                         │
│    → 指出盲区，温和但不回避问题                                  │
│  - empowering: 家长做出了值得肯定的回应                           │
│    → 具体肯定做法+说明积极影响+鼓励强化                           │
│                                                                 │
│ Input:  perception_report + memory + window_text                │
│ Output: MasterDecision { should_popup, direction, ... }         │
└─────────────────────────────────────────────────────────────────┘
```

### ③ Production / Student（生产层）— 共享组件

```
┌─────────────────────────────────────────────────────────────────┐
│ System: 你是弹窗生产 agent，将总控决策转化为自然语言弹窗            │
│                                                                 │
│ 生成约束:                                                        │
│  - 弹窗 ≤80 字                                                  │
│  - 语气: 温和、共情、非说教                                      │
│  - 结构: 看见→分析→建议（diagnostic）或 看见→肯定→鼓励（empowering）│
│  - 避免空洞表扬（"你真棒"）和冰冷诊断                            │
│                                                                 │
│ Input:  decision + perception + window_text + prev_popup_text   │
│ Output: PopupDraft { popup_insight }                            │
└─────────────────────────────────────────────────────────────────┘
```

### ④ Validator（验证器）— ⭐ TS 特有 + candidate_002 改进

```
┌─────────────────────────────────────────────────────────────────┐
│ System: 你是弹窗 tone 一致性验证器                                │
│                                                                 │
│ ── validating（鼓励式）判定标准 ──────────────────────────────   │
│ 必须同时满足:                                                    │
│  1. 指出家长的具体做法好在哪里（不是空洞的「你真棒」）              │
│  2. 说明为什么这种做法对孩子有积极影响                            │
│  3. 鼓励家长继续强化这种行为                                      │
│  4. ⭐【candidate_002 新增】全文不得出现用"但""然而""不过"         │
│     等转折引出对家长做法问题或盲区的分析；若出现，视为mixed，      │
│     判为不一致                                                   │
│                                                                 │
│ ── diagnostic（诊断式）判定标准 ──────────────────────────────   │
│ 必须同时满足:                                                    │
│  1. 指出家长的具体盲区或误解（不是泛泛而谈）                      │
│  2. 语气是「看见你、帮你看清」而非「批评你」                      │
│  3. 包含对家长处境的共情（不冰冷诊断）                            │
│                                                                 │
│ ── 不一致的典型症状 ────────────────────────────────────────    │
│  ❌ 假 empowering: 标签=empowering，内容实为分析盲区              │
│  ❌ 假 empowering: 标签=empowering，用了"但""然而""不过"后         │
│     指出问题 → 实质为 mixed【candidate_002 新增】                 │
│  ❌ 假 diagnostic: 标签=diagnostic，内容实为肯定家长               │
│  ✅ 方向对但程度不够 → 仍算一致                                  │
│                                                                 │
│ Input:  window_text + tone + popup_text                         │
│ Output: ValidationResult {                                       │
│   is_consistent: bool,                                          │
│   actual_tone_in_draft: "diagnostic"|"empowering"|"mixed",     │
│   mismatch_evidence: str,                                       │
│   suggestion: str                                               │
│ }                                                               │
└─────────────────────────────────────────────────────────────────┘
```

## 三、候选改进详情

### Edit 1: empowering 定义新增第 4 条规则

```

│  2. 说明积极影响     │       │  2. 说明积极影响                     │
│  3. 鼓励强化行为     │       │  3. 鼓励强化行为                     │
└─────────────────────┘       │  4. ⭐ 全文不得出现用"但""然而"      │
                              │     "不过"等转折引出对家长做法问题    │
                              │     或盲区的分析；若出现，视为mixed，  │
                              │     判为不一致                       │
                              └─────────────────────────────────────┘
```

### Edit 2: 不一致症状新增"转折词假 empowering"

```
Before:                                  After:
┌──────────────────────────────────┐    ┌──────────────────────────────────┐
│ 不一致的典型症状:                  │    │ 不一致的典型症状:                  │

```
