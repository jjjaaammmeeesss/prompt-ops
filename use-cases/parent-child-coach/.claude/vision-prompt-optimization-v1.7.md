## Q1：你为什么要做这个？真正想要的方向是什么？

家长在跟孩子谈话时，手机在一旁录音，两人的对话被**亲子沟通洞见智能体**听到。系统及时分析出一段话——让家长**更看懂孩子、看清自己、对两人的互动模式有认知**，于是有一种清醒感和醒悟感：

> "嗯，是的，我长期这样会有问题。"
> "的确不应该那样对待孩子。"

**一种终于明白发生了什么的清晰感，以及到底该怎么说怎么做的方向感。**

### 画面感五项

| 维度 | 内容 |
|---|---|
| 主角 | 跟孩子谈话时开着手机录音的家长（典型：妈妈） |
| 场景 | 手机在一旁录音，亲子对话正在进行 |
| 行为 | 看到智能体分析出的一段话，获得"看清自己+孩子+互动模式"的认知 |
| 感受 | 清醒感 + 醒悟感 + 方向感（"终于明白发生了什么"） |
| "哇"的理由 | 这段分析精准点出家长自己没看见的模式，不是泛泛安慰 |

## Q2：做完之后最大的变化是什么？谁受益？

**最大变化**：家长变得更懂教育，孩子就更安心。
**受益人**：最大受益人——家长；间接受益人——孩子。
