## 项目背景

- 生产系统: `realtime/stream_orchestrator.py` (主编排器) + `realtime/popup_generator.py` (Stage 2 弹窗生成器)
- 测试管线: `scripts/run_v418_pipeline.py` (批量测试器) + `demos/run_demo.py` (管线模拟器 simulate_pipeline)
- 窗口规格: `channel_spec.py` (唯一权威参数)
- 测试数据集: `data/new_12_independent.json` (12 题)

生产管线流程:
```
TextBuffer → TriggerEngine → ZhouYiAnalyzer(Stage 1) → P0硬拦截 → DebounceGate → PopupGenerator(Stage 2,含 FC_TONE_OFF + P2话术检查 + FC_STALE语义去重) → 弹窗
```

测试管线流程:
```
simulate_pipeline(快慢通道切窗) → 逐窗口 generate_popup(litellm直接调DeepSeek, 仅传system_prompt+window_text) → strip_pre_analysis → Codex裁判
```

## 缺陷 #1: 完全跳过 Stage 1 周易卦象分析 [致命]

**声称**: run_v418_pipeline.py 的 `generate_popup()` 完全没有调用 ZhouYiAnalyzer。prompt 第八节要求"上方附有周易卦象上下文"，但测试管线从未提供卦象/风险/容器判定。测试的不是生产系统行为。

**验证方法**:
1. 阅读 `scripts/run_v418_pipeline.py` 的 `generate_popup()` 函数
2. 确认它是否 import 或调用了 `ZhouYiAnalyzer` 或任何 zhouyi 相关模块
3. 阅读 `realtime/popup_generator.py` 的 `_build_messages()` (第330-381行)，确认生产代码将 zhouyi_context 注入了 system_content
4. 对比两者的 system message 构造

**声称证据**:
- 生产: `popup_generator.py:343-354` — `system_content = zhouyi_context + "\n" + self.system_prompt`
- 测试: `run_v418_pipeline.py:91-93` — `messages=[{"role":"system","content":system_prompt},{"role":"user","content":user_msg}]`

**验证方法**:
1. 阅读 `run_v418_pipeline.py:85-87` 的 user_msg 构造
2. 阅读 `popup_generator.py:357-376` 的 `_build_messages` 中 user_content 构造
3. 对比两者的差异

**声称证据**:
- 测试: `run_v418_pipeline.py:87` — `f"当前对话：\n{window_text}"`
- 生产: `popup_generator.py:370-376` — 含 type_instruction + extra_instruction + 输出格式要求

## 缺陷 #8: strip_pre_analysis 依赖 LLM 遵循它不知道的格式 [中危]

**声称**: v4.0.18 prompt 要求 LLM 输出 `==========` 预分析分隔符，但测试管线的 user_msg (`run_v418_pipeline.py:87`) 没有要求这个格式。LLM 可能直接输出弹窗正文而不加分隔符，strip 机制形同虚设。另外生产代码 `popup_generator.py:370-376` 的 user_msg 也未要求预分析格式。

**验证方法**:
1. 阅读 `run_v418_pipeline.py:60-82` strip_pre_analysis()

3. 阅读 `popup_generator.py:370-376` 生产 user_msg — 同样确认是否提及预分析格式
4. 阅读 system_prompt_v4.0.18.txt，确认 prompt 内部是否要求了该格式（如果 prompt 本身要求了，LLM 是否可能遵循）
5. 如果 prompt 内部有格式要求但 user_msg 没有，判定为 PARTIAL
