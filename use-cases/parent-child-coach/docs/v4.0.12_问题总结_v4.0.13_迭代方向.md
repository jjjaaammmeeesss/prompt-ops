# v4.0.12 问题总结 & v4.0.13 迭代方向

> **数据来源**：Gate 1 70 校标 × 1 轮 + Gate 4 12 独立 × 1 轮 + 已有文献
> **日期**：2026-07-29

---

## 一、v4.0.12 当前状态

| 指标 | 数值 | 评价 |
|------|:--:|------|
| 校标均分（70 条） | 0.626 | 中等——41% 通过率 |

## 二、问题分层

### A 层 · 致命问题（直接导致 judge veto，得分 = 0）

**A1. 事实性虚构（脑补家长话语/编造场景）** — 5 例独零 + 7 例双零中的 v4.0.12 侧

| 已知案例 | 问题描述 |
|----------|----------|
| C5-001（摆碗碎碗）| 虚构了家长内心独白，judge veto |
| DS_001（收盘子）| 编造了对话中不存在的家长话语，judge veto |
| C10-004 | Gate 4 veto——虚构了具体场景细节 |
| 5 例 Gate 1 v4.0.12 独零 | 触发了 judge 事实性错误否决 |

**根因**：v4.0.12 的禁脑补机制是**文本规则约束**——prompt 写了"禁止脑补"，但 LLM 写完一句话后不会真的检查自己有没有脑补。规则写在那里，LLM 读得到，但生成时不执行。

**v1.13 的对策**（可作为方向参考）：F1 逐句原文锚定——写完草稿后，逐句标注原文引用，标不出的句子删除。这是**结构性阻断**，不是文本约束。

---

**A2. 语气严重误判** — 部分案例中出现在鼓励/诊断选择上完全错误

| 表现 | 后果 |
|------|------|
| 该诊断时给了空洞赞美 | judge 触发"语气严重误判" veto |
| 该鼓励时给了诊断式（较少） | 家长感受差 |
| tone 覆盖门槛（≥2 积极行为）较粗 | 可能漏掉只有 1 个高质量积极行为的场景 |

---

### B 层 · 结构性问题（导致低分 < 0.5）

**B1. 洞察不够精准——停在泛泛而谈** — 12 例低分（< 0.5）

v4.0.12 在这些案例上方向对（没被 veto），但 judge 给出的 strategy_alignment 和 core_insight 得分偏低。典型表现：
- "换个角度"、"多理解孩子"——任何对话都能说的泛泛之谈
- 没有抓住这个对话**最独特**的那个矛盾点
- 弹窗像模板填空而非量身定制

**根因**：v4.0.12 依赖周易卦象做结构分析，但卦象分析是对话类型分类（是什么类型的困境），不是独特性挖掘（这个困境在这个家庭中展现的独特形式是什么）。

**v1.13 的对策**（可作为方向参考）：
- F3 三步自检——重复扫描（≥2 次出现的词=入口）、话外之话（"算了""随便"=在说别的事）、矛盾扫描（前后不一致=冲突点）
- 这是**发现方法论**——告诉 LLM "怎么找到独特的那个点"

---

**B2. 弹窗结构公式化** — 12 例低分中反复出现的模式

v4.0.12 的生成结构是：承认发心 → 揭示模式 → 给一个尝试。这个结构本身是正确的，但当 LLM 把它当成"三段论模板"填入时，弹窗就失去了人味。具体表现：
- "你是因为 X，才 Y"（承认发心段有明显模板痕迹）
- "你正戴着 Z 的眼镜"（框架术语泄露到家长面前）
- 建议句与前两段脱节——有时候像是两个独立段落拼接的

**根因**：v4.0.12 有几处"术语泄漏"——CBT 框架词汇出现在最终的家长可见弹窗中。人话感（natural_language）维度的得分因此偏低。

---

**B3. 无多样本防止重复** — 多窗口场景下可能重复照同一副眼镜

v4.0.12 没有避重机制。在同一次对话的多个弹窗窗口间，可能会出现两个弹窗都在说同一个问题、从同一角度切入。

---

### C 层 · 能力缺口（目前完全未覆盖的场景）

**C1. 反话/讽刺场景** — 完全盲区

v4.0.12 没有反话检测机制。当孩子说"你开心就好"、"反正我说什么你也不听"时：
- 按字面理解 → 可能解读为"孩子在认可家长"（完全误读）
- 生成鼓励式弹窗 → 火上浇油——家长以为自己做对了，其实是孩子放弃了沟通

ADV-07/08 类对抗用例就是专门测这个缺口。

---

**C2. 修复中对话的识别** — 无退出条件

当家长刚道过歉、气氛在缓和时，v4.0.12 仍然可能弹窗诊断——在修复进行中插话等于打断修复。

v1.13 有修复感知退出条件：道歉/示好/接纳 → 不诊断修复中的人。

---

**C3. 完美对话的过度干预**

tone 覆盖（≥2 积极行为 → 切鼓励式）是对"家长做得不错"的唯一保护机制。但如果家长做出 ≥3 个高质量积极行为——比如先倾听、再共情、再给选择——v4.0.12 只会切为鼓励式，而不是判定"这段对话不需要弹窗"。

v1.13 的方案：七层积极信念映射，≥3 条 → 纯鼓励/不弹。

---

### D 层 · 工程债务

**D1. Prompt 尺寸膨胀**

v4.0.10 → v4.0.12 增长了 7.1%。每次加新规则就加一段文本，长期会稀释 LLM 对核心规则的注意力。

**D2. Judge variance 大**

同一 case 跨轮得分可差 0.5+。这影响的不是 v4.0.12 的质量，而是我们评估它的能力。

## 四、v4.0.13 迭代方案

### 核心原则

1. **不改架构**：保持单 System Prompt + 周易 Stage 1 + 自由文本输出
2. **不增行数**：用替换代替添加——每一项新机制替换掉一段旧规则，不净增加
3. **先结构性阻断，再文本约束**：P0 修复不要写成"禁止 X"的文本规则，要写成 LLM 做完后必须自检的结构性步骤

---

### P0-1：反幻觉升级——从文本约束到结构性阻断

**目标**：将 A1 的 17% veto 率降至 < 5%。

**当前做法**（v4.0.12 第八节）：
```
禁止：脑补家长没说过的内心独白、动机；编造对话中不存在的话语...
```
这是文本约束——LLM 读得到但生成时不执行。

**v4.0.13 做法**：在弹窗生成指令末尾增加**写后自检步骤**（参考 v1.13 F1，但适配自由文本格式）：

```
写完后执行以下自审（不输出，在脑中完成）：

1. 把弹窗每一句逐个读一遍。问自己：这句话引用了对话中的哪个原文？
   如果某一句话在原文中找不到对应 → 删除这句话。
   
2. 弹窗中出现的人名、身份、关系 → 与原文严格一致。
   原文没说是"妈妈"还是"爸爸" → 写成"你"或"家长"。

3. 弹窗中出现的具体数字、时间、地点 → 必须来自原文，不得编造。

铁律：宁可弹窗短一截，不可多一个不存在的词。
```

**关键差异**：不是"禁止脑补"（约束），而是"逐句核对原文 → 标不出就删"（阻断）。v1.13 的测试数据显示这可以将事实错误减半（4→2/30）。

**替换位置**：替换 v4.0.12 第八节（全面禁脑补）的全部列表式禁令。

---

### P0-2：反话检测与强制响应

**目标**：补齐 C1 盲区。

**当前做法**：无。

**v4.0.13 做法**：在 tone 灵活覆盖段之前增加反话检测：

```
## 反话/讽刺检测（在判定 tone 之前执行）

孩子在对话中是否出现以下信号？
- 极端化修饰："你开心就好"、"反正"、"行行行"、"你说的都对"
- 表演式顺从：嘴上答应但语气是放弃挣扎
- 过度翻译：孩子说A但明显在表达B（"没什么"=有很多、"算了"=不想再说了）

如果 ≥2 条信号出现 → 孩子在使用讽刺/反话作为防御。
此时：
- 禁止赞美家长（反话场景中赞美=火上浇油）
- 禁止替孩子"翻译"反话（你翻译不了反话）
- 弹窗核心是：孩子用反话保护自己，说明他认为直接说真话不安全

弹窗语调：直接、不修饰、像朋友的手放在肩上——"你听到了吗"
```

**机制**：在生成弹窗前插入检测——检测到反话信号后，整段弹窗的语调、内容、策略都切换为反话响应模式。

---

### P1-1：发现方法论——从分类到定位

**目标**：将 B1 的低分率从 17% 降至 < 10%。

**当前做法**：周易卦象分析做对话类型分类（困卦/家人卦/…），然后弹窗策略映射。这告诉 LLM "这是什么类型的问题"，但没有告诉它"这个问题在这个具体对话中的独特形态是什么"。

**v4.0.13 做法**：在弹窗生成段之前，增加一段**三步定位**（参考 v1.13 F3）：

```
## 写稿前：三步定位（在脑中完成，不输出）

在落笔之前，用以下三步找到这个对话最独特的一个点：

1. **重复扫描**：对话中哪个词/句子出现了 ≥2 次？重复 = 孩子在强调或家长在回避。把重复最多的那一个挑出来——这就是弹窗的入口。

2. **话外之话扫描**：孩子有没有说"没什么"、"算了"、"随便"、"你开心就好"？
   这些词的字面意思和实际意思相反。标记出来——这是孩子在用自己的方式说"我不想说了"。

3. **矛盾扫描**：对话中有没有前后不一致的地方？孩子或家长有没有 A 句和 B 句互相矛盾？
   矛盾的位置 = 真正的冲突藏在下面。

你的诊断至少必须命中以上至少一项。如果三项都没命中，说明你没有看到这个对话中最独特的东西——重新读一遍对话，不要急着写。
```

**关键差异**：v4.0.12 的"结构>情绪"规则告诉 LLM 找什么层面（结构层 > 情绪层），但没有告诉它怎么找。v4.0.13 的三步告诉 LLM **扫描方法**——重复、话外之话、矛盾——这些是发现工具，不是分析标签。

**替换位置**：替换 v4.0.12 第五节（弹窗生成）中"模式揭示（先描述后命名 / 结构>情绪 / 控制→责任交还）"的"结构>情绪"部分。

---

### P1-2：语气校准细化

**目标**：减少 A2 语气误判和 B2 模板化。

**当前做法**：
- tone 灵活覆盖：≥2 积极行为 → 诊断式切鼓励式
- 发心承认段："你是因为 X，才 Y"

**v4.0.13 做法**：

**a) tone 覆盖门槛改为三层判定**（替换 ≥2 计数）：

```
## tone 灵活覆盖的三层判定

不要数积极行为有几个。改为问三个问题：

1. 家长"接住情绪"了吗？（孩子说完了、被理解了、气氛不再紧张）
2. 家长在"给选择"吗？（把决定权还给孩子，而非直接给答案）
3. 对话自然结束了吗？（最后一句话有没有修复/连接/和解的信号？）

- 三个全中 → 100% 纯鼓励（30-60 字，只点出闪光点，不诊断也不给建议）
- 中 2 项 → 鼓励为主（可加一句"如果想让 XX 更好，可以试试..."但不展开）
- 中 1 项或全不中 → 走标准诊断流程
```

**b) 替换发心承认段模板**（解决 B2 公式化）：

```
当前："你是因为担心孩子睡眠不够，才急着让对话收尾。"
替代方案：从对话中提取一个具体时刻，而非概括动机。
例如："他一件件把心里的事掏给你——竞选组长、被笑的记忆、猫...你一件件接住了。最后你给他挠背——这是在告诉他，无论多小的事，妈妈都在。"

原则：与其说"你是因为X"（概括动机=模板），不如说"你做了X"（描述行为=具体）。
```

---

### P2：修复感知与退出条件

**目标**：不打断正在修复中的对话。

**做法**：在 tone 覆盖段之前插入一段退出判定：

```
## 退出检查（在一切之前）

对话中是否出现了以下信号？
- 家长已经道歉："对不起"、"妈妈刚才不该"、"我做得不对"
- 家长已经示好：主动靠近、缓和语气、做出积极行动
- 气氛已经在修复：孩子从防御→松动、从沉默→开口

如果出现以上任一信号 → 这段对话不需要弹窗。家长正在修复关系——不要打断。
弹窗"看见"家长就够了——"你已经在修复了，不需要我的弹窗。"
```

---

### P3 暂缓项

- **避重机制**（B3）：多窗口场景发生率低，待 P0/P1 稳定后追加
- **完美对话不弹**（C3）：P1-2a 的三层判定已覆盖"三个全中=不弹"的情况
- **Prompt 瘦身**（D1）：P0/P1 的"替换旧规则"策略本身就是瘦身——删除旧规则文本，新机制写入

---

## 五、迭代执行顺序

```
P0-1（反幻觉升级）
  → 自测：手动跑 C5-001 + DS_001 + C10-004，确认不再被 veto
  → P0-2（反话检测）
    → 自测：手动跑 ADV-07 + ADV-08，确认识别反话
    → P1-1（三步定位）
      → P1-2（语气校准）
        → P2（修复感知）
```

**每步后验证**：重新跑 Gate 1（70 校标），确认：
1. veto 率下降（A1 修复的目标：17% → < 5%）
2. 均分不退化（不能因为加约束把好案例也拖低）
3. 低分率下降（B1 修复的目标：17% → < 10%）

---

## 六、不做的事

1. **不改为双 prompt 架构**：v1.13 的 System+User 双 prompt 没有在测试中展示优势
2. **不引入 JSON 输出**：v4.0.12 的自由文本在自然度上优于 JSON 格式
3. **不移植完整 F4 前置分流**：v1.13 53% empowering 率说明其分流阈值过松，直接移植会削弱诊断力
4. **不增加 prompt 总行数**：P0/P1 修改全部采用替换而非追加的方式

---

> **核心判断**：v4.0.12 的问题不是方向错误，是执行方式。——禁脑补：方向对，但用了文本约束而非结构性阻断。洞察：方向对，但用了分类标签而非发现方法。v4.0.13 要做的不是推翻重来，是把"禁止 X"升级为"做完后自检 X"，把"找什么"升级为"怎么找"。
