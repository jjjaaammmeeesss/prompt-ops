## 第一步：读懂局面 — 三爻分析

### 想法很简单

把一段对话切成三段看：

```
  开头 → 家长一开始什么状态？
  中间 → 中间有什么变化？
  结尾 → 最后走到了哪里？
```

每段只有两种状态：**在听**（控）或 **在炸**（失）。

### 三段拼起来 = 八种局面

```
  控-控-控  →  全程稳定              →  轻轻鼓励一下就好
  控-控-失  →  一直挺好最后有点波动    →  肯定"敢说真话"
  控-失-控  →  中间有冲突但修复了      →  肯定修复的能力
  控-失-失  →  从讲道理滑向争对错      →  需要提醒ta刹车
  失-控-控  →  开头急了但自己停住了    →  大声肯定"暂停"这个能力
  失-控-失  →  失控→冷静→又失控       →  指出"反复"这个模式
  失-失-控  →  很乱但最后长出秩序      →  肯定这个过程
  失-失-失  →  全程失控升级           →  紧急喊停
```

### 分析时不只看状态，还看两件事

**1. 有容器还是无容器？**

> "容器"就是"失控的时候，还留了一扇门吗"。
>
> 有容器：吼了但还在对话，没切断关系 → 风险可控。
> 无容器：威胁、羞辱、冷暴力 → 高风险，必须干预。

**2. 有没有踩红线？**

> 贬低孩子人格（"你就是笨"）、威胁抛弃（"我不要你了"）→ 不管其他条件，强制诊断式。

## 三道闸门

### 第一道：值不值得弹？

```
  纯日常闲聊（"今天吃什么""数学考几分"）
       → 不弹

  全程稳定陪伴，没有冲突没有教育契机
       → 不弹

  有冲突、有盲区、有值得肯定的瞬间
       → 放行
```

例外：即使表面日常，如果孩子说了"他们笑我""我肚子疼""我不敢说"→ 必须弹，风险提至中。

### 第二道：会不会太烦？

```
  刚弹过一样的内容        → 等 30 秒
  同一个卦象弹了太多次     → 不再重复
  局势突然恶化（风险升级）  → 立刻弹，不等冷却
  卦象变了（新局面）       → 弹新的
```

### 第三道：弹窗本身合格吗？

```
  家长明明说了伤人的话，
  但系统判成了"鼓励式"？     → 代码层强制改为诊断式 👈 FC_TONE_OFF

  新弹窗跟刚才弹的
  内容几乎一样？            → 拒绝弹出 👈 FC_STALE

  鼓励式弹窗缺了一句
  家长能直接说的话？         → 重试一次，还不合格就不弹
```

## 第二步：写弹窗 — 两种类型

### 诊断式（100-200字）：家长需要看到自己的盲区

```
  结构：
    "你是因为 [发心] —— 这个 [用心/担心] 是真的。"
    "但你说 [原文锚定]，孩子听到的不是 X，是 Y。"
    "你可以这样说：[具体话术]。"
```

### 鼓励式（30-60字）：家长做对了，命名那个瞬间

```
  结构：
    "你 [具体动作]，[具体效果]。"
    "下次可以这样说：[具体话术]。"
```

两种弹窗都强制要求**至少一句家长可直接说出的话**—— 以引号形式给出，不是建议，是可以直接用的台词。

## v4.0.17 修了什么

v4.0.16 的弹窗偶尔会冒出内部术语——比如把"多极"这种分析框架词说给家长听。

```
  修复前 ❌  "这个多极的时刻，他已经收到了。"
  修复后 ✅  "你放下了'只有一种对'的标准，他已经收到了。"
```

修了三处：指令、示例、术语表标注。详细见 [v4.0.16 → v4.0.17 变更章节](./v4.0.17_pipeline_guide.md#六v4016--v4017-变更)。

## 一句话总结每一层

| 层 | 一句话 |
|----|--------|
| 触发 | 攒够 200 字或出现敏感词 → 启动分析 |
| Stage 1 | 把对话切成开头/中间/结尾，看家长在听还是在炸 |
| 第一道闸 | 纯闲聊不弹，有冲突放行 |
| 第二道闸 | 刚弹过就等一等，局势变了就立刻弹 |
| Stage 2 | 给卦象+风险 → 写一段 30-200 字的话给家长 |
| 第三道闸 | 话没说对就改判，内容重复就不弹，缺台词就补上 |
