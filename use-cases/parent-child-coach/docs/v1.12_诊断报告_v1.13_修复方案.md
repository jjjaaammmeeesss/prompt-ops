## 根因分析

### 根因 #1：P0++（写前证据清单）形同虚设 — CRITICAL

v1.12 的事实错误从 v1.11 的 4/30（13.3%）**恶化**到 10/38（26.3%），翻倍。这说明"写前强制清单"作为纯文本指令无法阻止 LLM 虚构。

**具体虚构案例：**

| Case | 轮次 | 虚构内容 |
|------|------|----------|
| ADV-06 | R2 | "每天放学都看见" — 原文不存在 |
| ADV-03 | R2 | "虚构性别" |
| 饭桌挑食 | R1 | "妈妈"身份 — 原文未指定说话人性别/身份 |
| 饭桌挑食 | R1 | "青菜品种"细节 — 原文不存在 |
| 奶奶土方子 | R1 | 儿媳的话错安在女婿头上 |
| 奶奶土方子 | R3 | 儿媳的话错归给儿子 |

**根因：** LLM 在生成文本时不会真正"核对"证据清单 — 它只是读了指令然后继续按语言概率生成。需要一个**结构性阻断机制**而非纯文本指导。

**修复方向：** 将 P0++ 从"写前检查"升级为"写后自审 + 逐句标注原文引用"。

### 根因 #2：P6（反话检测）不一致 — HIGH

ADV-07: 虽然从 v1.11 的 0:3 改善到 1:2（1 轮认出反话），但 R2/R3 仍然失败。

**失败模式：**
- R2: v1.12 将反话误读为"早就放弃了被理解"（给挑衅赋予了过多心理学术语包装）
- R3: v1.12 的"用心良苦"反而强化了家长的"为你好"框架

**根因：** P6 的 3 条规则（极端化修饰/表演式顺从/过度翻译）只教了"识别反话信号"，但没教"识别反话后该做什么"。v1.12 在 R2/R3 识别了部分反话信号，但**弹窗内容仍然以真诚模式回应**，等于半吊子识别。

**修复方向：** P6 增加"识别反话后的强制响应规则"——一旦触发反话标记，弹窗必须(1)不赞美家长(2)不翻译孩子(3)直接指出反话作为防御机制。

### 根因 #3：P7（深度自检）L1/L2/L3 分级无效 — HIGH

ADV-06 R3: v1.12 完全漏掉"孩子说了两遍猫死了"这一核心结构性矛盾。

ADV-06 R2: v1.12 虽然洞察更深但虚构了事实，说明"深度"和"准确性"的 tradeoff 没有被 P0++ 约束。

**根因：** P7 的 L1/L2/L3 分级只是标签体系，没有具体的**发现方法论**。v1.12 知道"要达到 L2 以上"但不知道"怎么达到"。

**修复方向：** P7 增加具体的方法论步骤——(1)扫描重复词汇/句式(2)扫描"话外之话"（说A实际在说B）(3)扫描对话中的矛盾/不一致。

### 根因 #4：独立用例退化 — MEDIUM

v1.12 在正常对话上从 ~持平退化到 33.3% 决胜率（3:6 输给 v1.7）。

**根因：** 四个修复（P6/P7/P8/P0++）合计增加了约 900 字指令，让 prompt 对"正常对话"过度敏感——在不需要反话检测的对话中也启动反话检测逻辑，在不需要深度自检的对话中也尝试深挖。

**修复方向：** 增加一个简单的"前置分流"：先判断对话是否需要诊断式弹窗（P8 完美对话分流），在诊断式弹窗内部再分流是否需要反话检测和深度自检。

## v1.13 修复方案

### 修复 F1：P0++ 升级为"逐句原文锚定" — PRIORITY CRITICAL

**位置：** 替换现有 P0++（第零道：原文证据清单）段落

**改动：**
- 不再要求"写前列清单"，改为"写后逐句自审"
- 每句弹窗内容必须用 `[原文引用: "..."]` 格式标注其证据来源
- 凡标注不出的句子，**整段删除**
- 增加铁律：**"宁可不写一句，不可虚构一句"**

```
## 第零道：逐句原文锚定（写后自审 · 一票否决）

写完弹窗草稿后，对每一句执行以下自审：

1. 这句内容引用了对话中的哪一句话？标注原文引用。
2. 如果这句推断/翻译/评价没有对应的原文引用 → 删除。
3. 任何人名、关系、性别、身份 → 必须与原文一致，不得猜测。

铁律：宁可不写一句，不可虚构一句。宁可弹窗短一截，不可多一个不存在的词。
```

### 修复 F2：P6 升级 — "识别反话后的强制响应"

**位置：** 在现有 P6 (1B.2 反话/讽刺检测) 后追加

**改动：**
- 增加"反话确认后的强制响应规则"
- 一旦确认 ≥2 条反话信号：禁止赞美家长、禁止替家长翻译、必须直接指出反话是孩子的防御方式

```
### 反话确认后的强制响应规则

当 1B.2 确认 ≥2 条反话信号时，弹窗必须遵守：

- ❌ 禁止说"你做得对"、"你已经有进步"等赞美
- ❌ 禁止替孩子"翻译"反话的"真实含义"（你翻译不了反话——反话就是反话）
- ✅ 必须直接指出：孩子在使用讽刺/反话作为防御，这是信任破裂的信号
- ✅ 弹窗核心是："孩子用反话保护自己，说明他认为直接说真话不安全"
```

### 修复 F3：P7 升级 — "深度自检方法论"

**位置：** 在现有 P7 (写稿第 1.5 步：深度自检) 后追加

**改动：**
- 增加 3 个具体的发现方法步骤
- 重复扫描、话外之话扫描、矛盾扫描

```
### 深度自检的执行方法

在写诊断草稿前，执行以下三步扫描：

**步骤 A：重复扫描。** 把对话中同一个词/同一句话出现 ≥2 次的全部列出来。重复 = 孩子在强调 = 这就是诊断的入口。

**步骤 B：话外之话扫描。** 孩子说 A 但实际在说 B 的地方。标志词："没什么"、"算了"、"随便"、"你开心就好"、"没事"。

**步骤 C：矛盾扫描。** 对话中孩子或家长前后不一致的地方。A 句和 B 句互相矛盾 → 这里藏着真正的冲突。

你的诊断至少必须命中 A/B/C 中的一项，且必须引用具体原文。如果三项都没命中，说明你不够深入——重新读对话。
```

### 修复 F4：前置分流 — "诊断必要性判定"

**位置：** 在写稿第 1 步之前增加

**改动：**
- 在启动反话检测和深度自检之前，先判断"这个对话是否值得诊断"
- 减少对正常对话的过度干预

```
## 第 0.5 步：诊断必要性判定（写稿前分流）

在启动任何诊断流程前，先回答：

- 家长是否已经接住了孩子的情绪？（孩子说完了、被理解了、气氛不再紧张）
- 孩子是否自主做出了积极决定？
- 家长是否展现了"不评价、不比较、无条件接纳"？

如果以上三项全部是"是" → 走纯鼓励弹窗（100字以内，不诊断）。
如果 ≥2 项是"否" → 走诊断式弹窗，执行完整流程。
```

## 修复实施顺序

1. **F4 前置分流** — 先减少误弹窗（影响最小，收益最大）
2. **F1 P0++ 逐句锚定** — 解决虚构问题（影响最大）
3. **F2 P6 反话强制响应** — 解决 ADV-07
4. **F3 P7 深度方法论** — 解决 ADV-06
