## 一、测试结论（忠实端到端）

真实调用链 12 题：**8 题生成弹窗，4 题被 P0 硬拦截**。V1 召回 0.667、V3 tone 0.825、V4 内容 0.582、加权总分 0.437。
三类系统性缺陷：**Stage1 误判**（2 题）、**P0 过度保守**（2 题）、**V4 弹窗质量短板**（发心承认缺失 / 模式选错 / 跨窗引用）。

## 二、缺陷 A：Stage1 误判（隐性该弹信号未被识别）

**证据**：C10-002（睡不着/睡前焦虑）、C10-003（过马路不看车/安全隐患）被判「坤/低/不适用」→ P0 拦截，0 弹窗。标注认为该弹。

**位置**：`realtime/zhouyi_prompts.py` —— Stage1 判定 prompt 的「安全路由规则」（约 53-59 行）。

**现状**：安全路由规则只覆盖了部分"孩子困扰信号"，未纳入：
- **情绪困扰**：睡前焦虑、分离焦虑、社交孤立、过度承担责任、内疚（C10-002 类）
- **安全隐患**：过马路不看车、网约见面、烫伤、高空/湿滑（C10-003 类）

**改法建议**：
1. 扩充安全路由规则的信号清单，凡命中「情绪困扰 / 安全隐患」任一信号 → 风险**必须 ≥ 中**、建议类型**不得为「不弹窗」**。
2. 加一条"隐性该弹"判定：对话表面和谐但孩子表露情绪/安全隐患，不得判"日常稳态"。
3. 加 few-shot 负例示范：把 C10-002/C10-003 这类"表面平静但孩子有困扰"的对话，示范为「风险=中/高、建议=诊断式/鼓励式」。

## 三、缺陷 B：P0 过度保守（和谐但有教育契机被拦）

**证据**：C5-001（摆碗）、DS_001（收盘子）——对话表面和谐但有教育契机（家长全程在教/缺信任孩子），标注 `should_popup:true` 仍被 P0 拦。0 弹窗。

**位置**：`realtime/stream_orchestrator.py` 约 543-552 行，P0 硬拦截条件：
```python
if (self.stable_block_enabled and zhouyi_state.risk_level == "低"
        and zhouyi_state.trigram == Trigram.KUN
        and zhouyi_state.container_status == "不适用"):
    # 拦截
```
P0 只看 risk/卦象/容器三要素，**没看 Stage1 给的「建议类型」**。

**根因**：P0 本意是拦"无冲突无教育契机的纯日常"，但"和谐且有教育契机"（Stage1 会判建议类型=诊断式/鼓励式）也被误当纯日常拦了。

**改法建议**：P0 拦截条件收紧——**只有当 Stage1 建议类型也为「不弹窗」时才拦**；若 Stage1 已判「诊断式/鼓励式」（说明识别到教育契机/情绪信号），即使坤/低/不适用也放行进 Stage 2。即 P0 与 Stage1 的"建议类型"联动，而非只看三要素。

## 四、缺陷 C：V4 弹窗质量短板（权重 0.70，三类）

**证据**：V4=0.582。共性短板按触发频率：发心承认缺失（4 题）、模式选错（3 题）、跨窗引用（2 题）。

**位置**：`system_prompt_v4.0.19.txt` 弹窗生成规则段。

### C1. 发心承认缺失
- 证据：C10-006=0.2 / C5-003=0.25 / C5-005=0.15 / C3-002=0.2（V4a 分极低）。弹窗开门见山进诊断/洞察，未先承认家长好发心。
- 现状：prompt「1. 发心承认（始终最先）」（163 行）有要求，但**未强制、未对"家长以和谐/关心开场"特别强调**。
- 改法：把"发心承认"设为**硬前置**（不可省略），并特别强调：**当家长以和谐/关心/陪伴开场（哪怕后段有瑕疵），必须先承认其发心再诊断**。给 C10-006/C5-003/C5-005/C3-002 对应反例示范。

### C2. 模式选错（应鼓励却诊断）
- 证据：C10-004、C5-005 应鼓励却诊断（V4 门禁二触发）。
- 现状：prompt 的鼓励/诊断选择判定不足。
- 改法：强化"何时用鼓励 vs 诊断"边界——**当家长已自我修复、主动接住孩子情绪、对话温暖收尾（道歉→承诺→修复弧线）时，倾向鼓励式而非诊断式**。给反例示范（C5-005：家长最低落仍接住孩子安全感，系统却去诊断）。

### C3. 跨窗引用 / 事实锚定错误
- 证据：C5-004、C3-002 弹窗引用对话中不存在的原文（门禁一触发）。
- 现状：prompt「禁止脑补家长话语/行为」（195 行）有要求，但未执行到位。
- 改法：强化事实锚定**硬自检**——弹窗所有引号内"家长话语/行为"必须逐一对照输入原文，对话中未出现的一律删除。明确"只基于当前窗口 + 前文 900 字"，禁止跨窗口引用。
